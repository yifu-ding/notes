### KL 散度

#### [Q1] KL 散度（Kullback-Leibler Divergence）的定义

KL 散度衡量了两个概率分布之间的差异，其定义为：

$$
D_{KL}(P \| Q) = \sum_{x \in X} P(x) \log \frac{P(x)}{Q(x)}
$$

等价地，可以将其展开为交叉熵与熵的差：

$$
D_{KL}(P \| Q)
= \underbrace{-\sum_{x \in X} P(x) \log Q(x)}_{\text{交叉熵 } H(P,Q)}
  - \underbrace{\left(-\sum_{x \in X} P(x) \log P(x)\right)}_{\text{熵 } H(P)}
= H(P, Q) - H(P)
$$

关键性质：

- **非对称性**：$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$，因此 KL 散度不是距离度量。
- **非负性**：由 Jensen 不等式可证 $D_{KL}(P \| Q) \geq 0$，等号成立当且仅当 $P = Q$。
- 对 $D_{KL}(P \| Q)$ 来说，如果 $P(x)>0$ 但 $Q(x)=0$，KL 趋向 $+\infty$。更准确地说，它要求 $P$ 的支持集被 $Q$ 覆盖；反过来 $D_{KL}(Q \| P)$ 则要求 $Q$ 的支持集被 $P$ 覆盖。

> [!note] Forward KL vs Reverse KL
>
> 先约定一个常见语境：我们有一个**目标分布** $P$，想用一个可训练、可计算的**近似分布** $Q$ 去拟合它。
>
> - **Forward KL**：$D_{KL}(P \| Q)$，期望是对 $P$ 取的。
> - **Reverse KL**：$D_{KL}(Q \| P)$，期望是对 $Q$ 取的。
>
> 公式分别是：
>
> $$
> D_{KL}(P \| Q)=\mathbb{E}_{x\sim P}\left[\log\frac{P(x)}{Q(x)}\right]
> $$
>
> $$
> D_{KL}(Q \| P)=\mathbb{E}_{x\sim Q}\left[\log\frac{Q(x)}{P(x)}\right]
> $$
>
> **最关键的差别不在公式长什么样，而在“谁负责采样 / 谁作为权重”。**
>
> | | Forward KL $D_{KL}(P \| Q)$ | Reverse KL $D_{KL}(Q \| P)$ |
> |---|---|---|
> | 期望 / 权重来自谁 | 目标分布 $P$ | 近似分布 $Q$ |
> | 主要关心哪些区域 | $P$ 经常出现的地方 | $Q$ 自己会采样到的地方 |
> | 对 $P(x)>0, Q(x)=0$ | 损失 $\infty$，不能漏掉 $P$ 的支持集 | 该点因为 $Q(x)=0$ 不贡献损失，允许忽略 |
> | 对 $Q(x)>0, P(x)=0$ | 只要 $P(x)=0$，该点不贡献损失 | 损失 $\infty$，不能把概率放到 $P$ 完全不可能的地方 |
> | 行为特征 | **zero-avoiding / mass-covering**：避免 $Q=0$，倾向覆盖 $P$ 的所有模态 | **zero-forcing / mode-seeking**：把不想覆盖的区域设成 $Q=0$，倾向选择一个模态 |
> | 直观结果 | 容易“铺开”、平均化，可能生成模糊结果 | 容易“收缩”、挑峰值，可能 mode collapse |
> | 典型应用 | MLE、监督学习交叉熵、标准知识蒸馏 | VI 的 ELBO gap、RLHF / PPO 中常见 KL penalty、部分 mode-seeking 蒸馏 |
>
> - Forward KL 问的是：$P$ 会出现的地方，$Q$ 有没有覆盖到？所以它怕漏掉模式。
> - Reverse KL 问的是：$Q$ 自己会生成的东西，在 $P$ 看来合不合理？所以它怕生成到 $P$ 不支持的地方，但不怕漏掉 $P$ 的其他模式。
>
> **RLHF 中**：policy $\pi$ 对 reference model $\pi_{\text{ref}}$ 的惩罚常写作 $D_{KL}(\pi \| \pi_{\text{ref}})$。如果把 reference 当作目标分布 $P$、当前 policy 当作近似分布 $Q$，这就是 reverse KL。它主要惩罚“policy 实际会输出、但 reference 认为很不自然”的文本；但它不会强迫 policy 覆盖 reference 可能输出的所有文本。

#### [Q2] Reverse KL 是为了解决什么问题的？

**Reverse KL 不是“比 Forward KL 更正确”，而是在近似分布 $Q$ 表达能力有限时，选择一种不同的错误偏好。**

假设目标分布 $P$ 有两个高概率区域，也就是两个 mode；但我们手里的近似族 $Q$ 很弱，比如只能表示一个单峰高斯。此时 $Q$ 无法完美覆盖两个 mode，必须在两种错误之间选一个：

1. **Forward KL 的选择：尽量别漏掉 $P$ 的任何地方。**  
   因为 $D_{KL}(P \| Q)$ 的期望来自 $P$，只要 $P$ 经常出现的地方 $Q$ 给了极低概率，损失就很大。所以 $Q$ 会被迫把概率质量铺开，覆盖所有 mode。结果是：如果两个 mode 离得很远，$Q$ 可能落在两个 mode 中间，形成一个“平均但不真实”的近似。

2. **Reverse KL 的选择：只保证自己生成的东西靠谱。**  
   因为 $D_{KL}(Q \| P)$ 的期望来自 $Q$，$Q(x)=0$ 的地方根本不会被采样，也就不会贡献损失。所以 $Q$ 可以直接放弃 $P$ 的一部分 mode，只集中到其中一个高概率 mode 上。

公式上看：

$$
D_{KL}(Q \| P) = \sum_x Q(x) \log \frac{Q(x)}{P(x)}
$$

如果某个区域 $Q(x)=0$，这一项就是 0；所以 **Reverse KL 不惩罚“我没有覆盖 $P$ 的某个 mode”**。但如果某个区域 $Q(x)>0$ 且 $P(x)$ 很小，那么 $\log \frac{Q(x)}{P(x)}$ 会很大；所以 **Reverse KL 强烈惩罚“我把概率放到了 $P$ 认为不合理的地方”**。

一个最小例子：

| 位置 | 目标分布 $P$ | 近似分布 $Q$ |
|---|---:|---:|
| mode A | 0.5 | 1.0 |
| mode B | 0.5 | 0.0 |

这里 $Q$ 只选择了 mode A，完全放弃 mode B。

- 对 Forward KL：$P(B)=0.5$ 但 $Q(B)=0$，所以 $D_{KL}(P \| Q)=\infty$，这是不可接受的。
- 对 Reverse KL：$Q(B)=0$，B 不贡献损失；只要 A 在 $P$ 下也合理，损失是有限的。因此这种“只挑一个 mode”的行为是允许的。

**Reverse KL 解决的核心问题**：当我们不想要“平均覆盖所有可能答案”，而是想让模型专注在一个高概率、清晰、合理的答案区域时，Reverse KL 比 Forward KL 更合适。

**但代价也很重要**：Reverse KL 容易造成 **mode collapse**，也就是只学到目标分布的一部分，低估不确定性，漏掉其他合理答案。所以它适合“生成结果要集中、确定、不要乱跑”的场景，但不适合“必须完整覆盖所有可能性”的场景。

#### [Q3] Reverse KL 在哪里会用到？

**1. RLHF / PPO 的 KL 惩罚项**

RLHF 的优化目标常写作：

$$
\max_{\pi} \mathbb{E}_{y \sim \pi(\cdot|x)} \left[ r(x, y) \right]
- \beta \, D_{KL}\!\left(\pi(\cdot|x) \,\|\, \pi_{\text{ref}}(\cdot|x)\right)
$$

如果把 reference model $\pi_{\text{ref}}$ 当作目标分布 $P$，把当前 policy $\pi$ 当作近似分布 $Q$，那么这个 KL 就是：

$$
D_{KL}(Q \| P)=D_{KL}(\pi \| \pi_{\text{ref}})
$$

它的意思是：**只检查当前 policy 实际会采样的输出，在 reference model 看来是否离谱。**

- 如果 policy 给某个回答很高概率，而 reference 几乎不会这么说，$\log \frac{\pi}{\pi_{\text{ref}}}$ 很大，惩罚就大。
- 如果 reference 能说很多种回答，但 policy 只选择其中一部分，Reverse KL 不会强制 policy 覆盖 reference 的全部可能回答。

所以它适合 RLHF：我们关心的是“模型实际输出不要跑偏”，而不是“模型必须保留 base model 的所有输出模式”。实际实现里，完整 KL 是对整段 response 分布的 KL；工程上常用 sampled tokens 上的 log-prob 差近似：

$$
\sum_t \left[\log \pi(y_t|x,y_{<t}) - \log \pi_{\text{ref}}(y_t|x,y_{<t})\right]
$$

**2. 变分推断（Variational Inference / VAE）**

VI 的目标是用简单的 $q(\mathbf{z})$ 近似复杂的真实后验 $p(\mathbf{z}|\mathbf{x})$。ELBO 和真实 log evidence 的关系是：

$$
\log p(\mathbf{x})
= \text{ELBO}(q) + D_{KL}(q(\mathbf{z}) \,\|\, p(\mathbf{z}|\mathbf{x}))
$$

所以最大化 ELBO 等价于最小化：

$$
D_{KL}(q(\mathbf{z}) \,\|\, p(\mathbf{z}|\mathbf{x}))
$$

这也是 Reverse KL：近似后验 $q$ 是前面的分布，真实后验 $p$ 是后面的分布。它会让 $q$ 倾向于选择后验中的某个 mode，而不是平均覆盖所有 mode。

> [!warning] VAE 里容易混淆的一点
> VAE 训练 loss 里常见的显式 KL 项是 $D_{KL}(q_\phi(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))$，这是把 encoder 的近似后验拉向 prior 的正则项；而从 ELBO gap 角度看，最大化 ELBO 等价于最小化 $D_{KL}(q_\phi(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}|\mathbf{x}))$，也就是近似后验到真实后验的 reverse KL。两者方向都是“$q$ 在前”。

**3. 知识蒸馏（Knowledge Distillation）**

标准蒸馏通常最小化：

$$
D_{KL}(P_{\text{teacher}} \| Q_{\text{student}})
$$

这相当于让 student 覆盖 teacher 的完整 soft label 分布，包括 teacher 对非最大类别的“暗知识”（dark knowledge）。

如果改成 Reverse KL：

$$
D_{KL}(Q_{\text{student}} \| P_{\text{teacher}})
$$

student 会更关注 teacher 最确信的类别或区域，输出更尖锐，适合某些高压缩或追求确定性的场景。但代价是可能丢掉 teacher 分布里的次优类别信息。

### 交叉熵损失函数

#### [Q4] 交叉熵损失函数的公式与物理意义

交叉熵（Cross-Entropy）度量了用预测分布 $Q$ 来编码真实分布 $P$ 所需的平均比特数：

$$
H(P, Q) = -\sum_{x \in X} P(x) \log Q(x)
$$

在分类任务中，$p$ 为真实标签，$q$ 为模型预测，$N$ 为样本数。二分类的交叉熵损失为：

$$
L = -\frac{1}{N} \sum_{i=1}^{N} \left[ p_i \log(q_i) + (1 - p_i) \log(1 - q_i) \right]
$$

**物理意义**：

- 熵 $H(P)$ 是用最优编码表示 $P$ 所需的最少平均比特数。
- 交叉熵 $H(P, Q)$ 是用 $Q$ 的编码方案来表示 $P$ 所需的平均比特数。
- $D_{KL}(P \| Q) = H(P, Q) - H(P)$ 就是因为用 $Q$ 代替 $P$ 而多消耗的额外比特数。

当两个分布完全一致时，交叉熵等于 $P$ 本身的熵，损失最小；预测分布与真实分布偏差越大，交叉熵越大，表示预测错误程度越高。

#### [Q5] KL 散度与交叉熵的区别

|  | 交叉熵 $H(P, Q)$ | KL 散度 $D_{KL}(P \| Q)$ |
|---|---|---|
| 公式 | $-\sum P(x) \log Q(x)$ | $\sum P(x) \log \frac{P(x)}{Q(x)}$ |
| 关系 | $H(P, Q) = H(P) + D_{KL}(P \| Q)$ | $D_{KL}(P \| Q) = H(P, Q) - H(P)$ |
| 对称性 | 不对称 | 不对称 |
| 下界 | $H(P)$（当 $Q = P$ 时取到） | 0（当 $Q = P$ 时取到） |

在训练时，真实分布 $P$ 固定不变，$H(P)$ 是与参数无关的常数。最小化交叉熵和最小化 KL 散度等价——二者梯度完全相同，只差一个常数项。

实践中使用交叉熵而不是 KL 散度的原因：计算更简单，不需要额外计算 $H(P)$；当真实分布是 one-hot 时，交叉熵退化为 $-\log q_{\text{true}}$，即模型对正确类别赋予的概率的对数，极为高效。

#### [Q6] 多任务学习中各 loss 差异过大怎么处理

多任务学习中，不同任务的 loss 量级差异过大，容易导致梯度被量级大的任务主导，量级小的任务难以有效学习。常见处理方式：

1. **人工加权**：给每个任务的 loss 设置权重 $w_k$，手动调整各任务贡献：$L = \sum_k w_k L_k$。简单直接，但需要人工搜索权重。

2. **不确定性加权（Uncertainty Weighting）**：通过可学习的任务不确定性参数 $\sigma_k$ 自动调整权重（Kendall et al. 2018）：
$$
L = \sum_k \frac{1}{2\sigma_k^2} L_k + \log \sigma_k
$$

3. **梯度归一化（GradNorm）**：动态调整各任务权重，使得所有任务梯度的 L2 范数在相同量级上，保证优化方向平衡。

4. **loss 归一化**：将每个任务的 loss 除以其历史均值或初始值进行标准化，使不同任务处于相同量级，减少人工干预。

5. **任务特定的 loss 函数**：根据任务性质选择量级合适的损失，从设计阶段就避免引入量级差异。

#### [Q7] 分类问题为什么用交叉熵而不用均方误差（MSE）⭐️

**1. 梯度消失问题**

以 Sigmoid 输出 $\hat{y} = \sigma(z)$ 为例：

- 用 MSE 时：$\dfrac{\partial L}{\partial z} = (\hat{y} - y) \cdot \hat{y}(1 - \hat{y})$，含饱和项 $\hat{y}(1-\hat{y})$，当预测值接近 0 或 1 时趋近于 0，梯度消失，训练缓慢。
- 用交叉熵时：$\dfrac{\partial L}{\partial z} = \hat{y} - y$，梯度简洁，预测越错梯度越大，收敛更快。

**2. 输出空间匹配**

分类输出经过 softmax/sigmoid 后是概率值，交叉熵天然度量两个概率分布之间的差异；MSE 假设误差服从高斯分布，面向连续值回归，与概率输出的数学结构不匹配。

**3. 概率敏感性**

交叉熵对 $-\log q$ 进行惩罚，对低置信度的正确预测（如 $\hat{y} = 0.51$）也会给予较大惩罚，鼓励模型输出高置信度的预测。MSE 的二次惩罚在此场景下不够敏感。

> MSE 适合回归（预测连续值，误差服从高斯假设）；交叉熵适合分类（输出概率分布，度量信息差异）。两者不是好坏之分，而是适用场景不同。

#### [Q8] 什么是信息增益

信息增益（Information Gain）是决策树中用于选择最佳分裂特征的评价指标，衡量在某一特征已知的情况下样本集合不确定性减少的程度：

$$
\text{IG}(D, A) = H(D) - H(D \mid A)
$$

其中：

$$
H(D) = -\sum_{k} \frac{|C_k|}{|D|} \log \frac{|C_k|}{|D|}
\qquad
H(D \mid A) = \sum_{v} \frac{|D_v|}{|D|} H(D_v)
$$

信息增益越大，用该特征分裂后纯度提升越多，该特征越应作为分裂节点。

局限性：信息增益偏向选择取值种类多的特征（如 ID 列，每个取值对应一个样本，熵变为 0）。C4.5 算法用**信息增益率**来修正：

$$
\text{IGR}(D, A) = \frac{\text{IG}(D, A)}{H_A(D)}
$$

其中 $H_A(D)$ 是特征 $A$ 本身的熵，取值种类越多，$H_A$ 越大，起到惩罚高基数特征的作用。

#### [Q9] 多分类的 Softmax 交叉熵损失

多分类问题中，输出层使用 Softmax 将 logit 归一化为概率分布：

$$
p_{ic} = \frac{e^{l_{ic}}}{\sum_{j} e^{l_{ij}}}
$$

多分类交叉熵损失为：

$$
L = -\frac{1}{N} \sum_{i=1}^{N} \sum_{c=1}^{M} y_{ic} \log(p_{ic})
$$

其中 $N$ 为样本数，$M$ 为类别数，$y_{ic}$ 为指示函数（样本 $i$ 真实类别等于 $c$ 时取 1，否则取 0），$p_{ic}$ 为预测概率。

由于 $y_{ic}$ 是 one-hot，每个样本的损失只有真实类别那一项非零，化简为：

$$
L_i = -\log(p_{i, y_i})
$$

即只惩罚模型对正确类别赋予的概率——正确类别预测概率越低，损失越大。

#### [Q10] 多分类交叉熵、二分类交叉熵

**多分类（Softmax + Cross-Entropy）**：

$$
L = -\frac{1}{N} \sum_{i} \sum_{c=1}^{M} y_{ic} \log\!\left(\frac{e^{l_{ic}}}{\sum_{j} e^{l_{ij}}}\right)
$$

**二分类（Binary Cross-Entropy，BCE）**：

输出层使用 Sigmoid：$p_i = \sigma(l_i) = \dfrac{1}{1+e^{-l_i}}$，损失为：

$$
L = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(p_i) + (1 - y_i) \log(1 - p_i) \right]
$$

其中 $y_i \in \{0, 1\}$ 是真实标签，$p_i$ 是模型预测为正类的概率。

BCE 与多分类交叉熵的一个关键区别：

- 多分类用 Softmax，所有类别概率之和严格为 1，各类互斥。
- 二分类用独立的 Sigmoid，每个输出节点独立预测，更适合**多标签分类**（各类别不互斥，同一样本可同时属于多类）。

#### [Q11] Softmax 的 $e$ 次方超过 float 范围怎么办

当 logit $l_i$ 很大时，$e^{l_i}$ 会上溢（overflow），超过 float32 最大值（约 $3.4 \times 10^{38}$），导致 `inf`。

**解决方案：减去最大值（log-sum-exp 稳定化）**

$$
p_i
= \frac{e^{l_i}}{\sum_j e^{l_j}}
= \frac{e^{l_i - l_{\max}}}{\sum_j e^{l_j - l_{\max}}}
\quad \text{其中 } l_{\max} = \max_j l_j
$$

分子分母同除以 $e^{l_{\max}}$，结果不变，但所有指数都平移到 $\leq 0$ 的范围，彻底避免上溢。

下溢（underflow）不是主要问题：当 $l_i - l_{\max}$ 极小时，$e^{l_i - l_{\max}} \approx 0$，表示该类别概率极低，是正确的数值行为。

配合 Log-Softmax 计算更稳定：

$$
\log p_i = l_i - \log\sum_j e^{l_j} = (l_i - l_{\max}) - \log\sum_j e^{l_j - l_{\max}}
$$

PyTorch 的 `nn.CrossEntropyLoss` 内部已做数值稳定化处理，实际使用时无需手动实现。

###  负对数似然（NLL）

#### [Q12] 负对数似然（NLL）会用在哪里？为什么要取负对数？

更准确的名称是**负对数似然**（Negative Log-Likelihood，NLL）。“自然”指通常采用自然对数 $\ln$，但换用其他底数只会整体缩放 Loss。

给定正确结果 $y$，模型为其分配概率 $p_\theta(y\mid x)$，NLL 为：

$$
\mathcal{L}_{\mathrm{NLL}}
=
-\log p_\theta(y\mid x)
$$

**在 LLM 训练中的常见位置：**

| 阶段 | 被最大化的正确事件 | 常见 Loss |
| --- | --- | --- |
| Pre-training | 每个真实的下一个 token | Token-level NLL / Cross-Entropy |
| SFT / Fine-tuning | 目标回答中的 token | Response-token NLL / Cross-Entropy |
| Reward Modeling | 人类选择 winner 而非 loser | $-\log\sigma(r_w-r_l)$ |
| DPO | chosen 优于 rejected | 二元偏好的负对数似然 |
| 分类、安全模型 | 正确类别或标签 | Binary / Multi-class Cross-Entropy |

> [!note] NLL 与交叉熵的关系
> 当真实标签是 one-hot 时，交叉熵只保留正确类别对应的一项，因此就等于 NLL：  
> $H(P,Q)=-\sum_i P_i\log Q_i=-\log Q_{\mathrm{correct}}$。

**为什么使用负对数？**

1. **把最大化概率变成最小化 Loss。**  
   训练框架通常执行梯度下降，而最大化似然 $p$ 等价于最小化 $-\log p$。

2. **把连乘变成连加。**  
   一个序列的概率是各 token 概率的乘积：
   $p(y\mid x)=\prod_t p(y_t\mid x,y_{<t})$。  
   取对数后变为求和：
   $-\log p(y\mid x)=-\sum_t\log p(y_t\mid x,y_{<t})$，更易计算和优化。

3. **数值更稳定。**  
   大量小概率连乘容易下溢到 0；log-space 求和可以避免这一问题。

4. **对“自信的错误”惩罚更强。**  
   正确事件的预测概率趋近 0 时，$-\log p$ 会迅速增大；概率趋近 1 时，Loss 趋近 0。

5. **具有明确的统计意义。**  
   最小化 NLL 就是最大似然估计；在数据充分且模型合适时，它会推动预测分布逼近真实数据分布。

> [!important] 它并非对所有任务都更好
> NLL 适用于模型输出**概率分布**、目标是提高观测数据似然的任务。连续值回归常使用 MSE/Huber Loss；排序、度量学习和强化学习也可能使用 ranking loss、contrastive loss 或 policy objective。应根据输出的概率假设和任务目标选择损失。

##### Softmax 激活函数实现 #easy

*Question* 编写一个 Python 函数，计算给定分数列表的 softmax 激活值。函数需处理数值稳定性问题，防止对较大值取指数时发生溢出。返回浮点数列表。

*E.g.* 输入 `scores = [1, 2, 3]`，输出 `[0.0900, 0.2447, 0.6652]`

*原理* Softmax 将一组数值转换为概率分布，每个元素的概率正比于其指数值除以所有元素指数值之和：

$$\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}$$

*数值稳定性* 直接计算 $e^{x_i}$ 在 $x_i$ 很大时会溢出。常见技巧：减去最大值 $\max(x)$ 再取指数，结果不变但避免溢出：

$$\text{softmax}(x_i) = \frac{e^{x_i - \max(x)}}{\sum_j e^{x_j - \max(x)}}$$

*Solution*

```python
import numpy as np

def softmax(scores: list[float]) -> list[float]:
    max_scores = np.max(scores, axis=-1, keepdims=True)
    shifted = scores - max_scores
    res = np.exp(shifted) / np.sum(np.exp(shifted), axis=-1, keepdims=True)
    return res
```

##### 单神经元（Sigmoid 二分类） #easy

*Question* 模拟一个带 sigmoid 激活函数的单神经元，用于二分类。函数接收特征向量列表（每个向量包含多个特征）、真实二值标签、权重向量和偏置，返回 sigmoid 激活后的预测概率列表，以及预测概率与真实标签之间的均方误差（MSE），均保留四位小数。

*E.g.* 输入 `features = [[0.5, 1.0], [-1.5, -2.0], [2.0, 1.5]]`，`labels = [0, 1, 0]`，`weights = [0.7, -0.4]`，`bias = -0.1`，输出 `([0.4626, 0.4134, 0.6682], 0.3349)`

*原理*

1. 对每个输入向量计算加权求和：$z = \mathbf{w} \cdot \mathbf{x} + b$
2. 经 sigmoid 激活得到预测概率：$\hat{y} = \sigma(z) = \dfrac{1}{1 + e^{-z}}$
3. 计算 MSE：$\text{MSE} = \dfrac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2$

*Solution*

```python
import numpy as np

def single_neuron_model(features, labels, weights, bias):
    features = np.array(features)   # (n, m)
    labels = np.array(labels)       # (n,)
    weights = np.array(weights)     # (m,)

    z = features @ weights + bias   # (n,)

    def sigmoid(x):
        return 1 / (1 + np.exp(-x))

    logits = sigmoid(z)             # (n,)
    mse = np.mean((logits - labels) ** 2)

    probabilities = [round(p, 4) for p in logits.tolist()]  # 或者 probabilities = list(logits) 
    return probabilities, round(float(mse), 4)
```

> [!bug] 常见错误
> - `np.ndarray(data)` ❌ → `np.array(data)` ✅（前者接收 shape 整数，后者接收数据）
> - `weights * features` ❌ → `features @ weights` ✅（需要点积，不是逐元素乘）
> - `np.sum(np.mean(...))` ❌ → `np.mean(...)` ✅（1D 数组上 mean 已是标量）

##### Log-Softmax 函数实现 #easy

*Question* 给定一个 1D numpy 数组，计算其 log-softmax 值。

*E.g.* 输入 `[1, 2, 3]`，输出 `[-2.4076, -1.4076, -0.4076]`

*原理* Log-softmax 是 softmax 取对数，数值上更稳定：

$$\log\text{softmax}(x_i) = x_i - \log\sum_j e^{x_j}$$

减去 $\max(x)$ 后等价形式（防溢出）：

$$= (x_i - \max x) - \log\sum_j e^{x_j - \max x}$$

*Solution 1（直接法，更稳定）*

```python
import numpy as np

def log_softmax(scores: np.ndarray) -> np.ndarray:
    shifted = scores - np.max(scores)
    return shifted - np.log(np.sum(np.exp(shifted)))
```

*Solution 2（先算 softmax 再取 log）*

```python
import numpy as np

def log_softmax(scores: list) -> np.ndarray:
    scores = np.array(scores)
    scores_max = np.max(scores, axis=-1, keepdims=True)
    shifted = scores - scores_max
    sm = np.exp(shifted) / np.sum(np.exp(shifted), axis=-1, keepdims=True)
    return np.log(sm)
```

> [!tip] 两种写法的区别
> Solution 2 结果正确，但先算 softmax 再取 log，当某个 softmax 值极小时 `log(~0)` 会有精度损失。Solution 1 跳过中间的 softmax，直接用减法得到 log-softmax，数值更稳定，也是工业实践（如 PyTorch `F.log_softmax`）的做法。

##### ReLU 激活函数实现 #easy

*Question* 实现 ReLU（Rectified Linear Unit）激活函数：输入大于 0 时返回原值，否则返回 0。

*E.g.* `relu(0) → 0.0`，`relu(1) → 1.0`，`relu(-1) → 0.0`

*原理*

$$\text{ReLU}(x) = \max(0, x)$$

*Solution*

```python
def relu(x: float) -> float:
    return float(max(0, x))
```

###### Leaky ReLU 激活函数实现 #easy

*Question* 实现 Leaky ReLU 激活函数：输入大于 0 时返回原值，否则返回 `alpha * x`（默认 `alpha=0.01`）。

*E.g.* `leaky_relu(0) → 0`，`leaky_relu(1) → 1`，`leaky_relu(-1) → -0.01`，`leaky_relu(-2, alpha=0.1) → -0.2`

*原理*

$$\text{LeakyReLU}(x) = \begin{cases} x & x > 0 \\ \alpha x & x \leq 0 \end{cases}$$

相比 ReLU，负值区域保留一个小斜率 $\alpha$，缓解 **神经元死亡（dying ReLU）** 问题。

*Solution*

```python
def leaky_relu(z: float, alpha: float = 0.01) -> float:
    return z if z > 0 else alpha * z
```

##### 两个正态分布的 KL 散度 #easy

*Question* 计算两个正态分布 $P \sim \mathcal{N}(\mu_p, \sigma_p^2)$ 和 $Q \sim \mathcal{N}(\mu_q, \sigma_q^2)$ 之间的 KL 散度，返回浮点数。

*E.g.* `kl_divergence_normal(0.0, 1.0, 1.0, 1.0) → 0.5`

*原理* KL 散度衡量分布 $P$ 相对于参考分布 $Q$ 的差异，对两个正态分布有解析公式：

$$\text{KL}(P \| Q) = \log\frac{\sigma_q}{\sigma_p} + \frac{\sigma_p^2 + (\mu_p - \mu_q)^2}{2\sigma_q^2} - \frac{1}{2}$$

==知道 KL 散度公式就行==

验证示例：$\log\frac{1}{1} + \frac{1 + (0-1)^2}{2 \cdot 1} - \frac{1}{2} = 0 + 1 - 0.5 = 0.5$ ✓

*Solution*

```python
import math

def kl_divergence_normal(mu_p: float, sigma_p: float, mu_q: float, sigma_q: float) -> float:
    return (math.log(sigma_q / sigma_p)
            + (sigma_p**2 + (mu_p - mu_q)**2) / (2 * sigma_q**2)
            - 0.5)
```
